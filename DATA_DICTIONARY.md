# Data Dictionary

| Column | Description |
|---|---|
| CustomerID | Unique customer identifier |
| TenureMonths | Number of months the customer has stayed |
| ContractType | Month-to-Month, One Year, or Two Year |
| InternetService | Fiber, DSL, or 5G Home |
| SupportTickets | Number of support tickets |
| SatisfactionScore | Customer satisfaction score from 1 to 5 |
| MonthlyCharges | Monthly billing amount |
| MonthlyUsageGB | Monthly data usage in GB |
| AutoPay | Whether automatic payment is enabled |
| PaymentMethod | Main payment method |
| Churned | 1 = churned, 0 = retained |

The dataset is synthetic. No real customer or company data is used.
